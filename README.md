# SEO Inspector Pro

Professional Website Crawling & SEO Auditing Tool for Windows, built with Python 3.12+ and CustomTkinter.

## Run

```bash
pip install -r requirements.txt
python main.py
```

## Features

- Dark professional single-window interface with sidebar navigation, toolbar, status bar, and live progress.
- Async aiohttp crawler with concurrency, retries, connection pooling, timeout handling, pause, resume, stop, depth limits, page limits, duplicate prevention, and optional robots.txt support in the crawler core.
- Live dashboard metrics, page inventory, SEO issues, images, links, resources, emails, social media, security headers, sitemap and robots.txt pages.
- Phase 2 export page with professional disabled export actions.
- File logging to `logs/application.log`.
